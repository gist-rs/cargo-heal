# cargo-heal

Binary-only distribution of the `cargo-heal` code healer — a modelless,
corpus-driven fixer that repairs Rust code in place. This repo ships
releases, installers, and this README; **no source is published here.**

## What it does

`cargo heal` heals mechanical issues across pluggable domains:

- `clippy_lints` — `cargo clippy` warnings (style / complexity / perf classes)
- `rust_perf` — Rust performance patterns
- `kernel_opt` — GPU kernel optimization rules
- `docker` — Dockerfile bounded fixes (hadolint-shaped findings)
- `rustc_errors` — compile-error repair keyed by rustc error code (`--fix-compile`)
- latent retrieval — span-level rule retrieval over the enabled domains (`--suggest` / `--fix`)

Modelless by construction: no trained weights, no network calls at heal time.

## Install

macOS / Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/gist-rs/cargo-heal/main/install.sh | sh
```

Windows (PowerShell):

```powershell
iwr -useb https://raw.githubusercontent.com/gist-rs/cargo-heal/main/install.ps1 | iex
```

Homebrew (prebuilt formula — nothing is compiled):

```sh
brew tap gist-rs/tap && brew install cargo-heal
```

Scoop:

```powershell
scoop bucket add gist-rs https://github.com/gist-rs/scoop-bucket
scoop install cargo-heal
```

Installers place `cargo-heal` in `~/.cargo/bin` (Windows: `%USERPROFILE%\.cargo\bin`),
so the `cargo heal` subcommand works in any Rust project.

## Use

```sh
cargo heal --suggest src/     # ranked suggestions — does not write
cargo heal --fix src/         # bounded, compile-gated fixes
cargo heal --help             # everything else
```

## Verify

Every release carries a `SHA256SUMS` file and the installers verify
automatically. To verify by hand:

```sh
sha256sum -c SHA256SUMS
```
